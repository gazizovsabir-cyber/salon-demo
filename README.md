# Шаблон сайта для салона красоты

Одностраничный сайт-заявка: HTML, CSS и немного JavaScript. Сборка и установка ничего не требуют, достаточно положить папку на любой хостинг.

## Из чего состоит

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка страницы |
| `assets/js/config.js` | **Все настройки клиента**: название, цвет, тексты, фото, контакты, форма |
| `assets/js/presets.js` | Готовые тексты и услуги для 5 типов бизнеса |
| `assets/js/main.js` | Логика: подстановка данных, меню, услуги, галерея, форма |
| `assets/css/styles.css` | Стили. Цвета и размеры собраны в начале файла (`:root`) |
| `assets/css/fonts.css`, `assets/fonts/` | Шрифты Manrope и Noto Serif Display (лицензия OFL). Хранятся на сайте, чтобы не зависеть от Google Fonts |
| `assets/img/` | Фотографии сайта |
| `privacy.html` | Шаблон политики обработки персональных данных |
| `examples/send-telegram.php` | Пример обработчика, который пересылает заявки в Telegram |

## Как открыть

Откройте `index.html` в браузере. Если шрифты или фото не грузятся, запустите любой локальный сервер в этой папке (например, расширение Live Server в VS Code).

## Как сделать сайт для нового клиента

1. Скопируйте папку `template` и назовите её по клиенту.
2. Откройте `assets/js/config.js` и поменяйте:
   - `brand.name` — название (оно же крупная надпись на первом экране и в подвале);
   - `businessType` — тип бизнеса: `universal`, `hair`, `barber`, `nails`, `brows`;
   - `accent` — цвет акцента (берите тёмный приглушённый оттенок: на нём белый текст);
   - `hero`, `about` — тексты и фото;
   - `services` — свои услуги (или оставьте `null`, тогда возьмутся из типа бизнеса);
   - `gallery` — фото работ: в `src` указать путь к файлу, например `assets/img/work-1.jpg`;
   - `contacts` — адрес, телефон, мессенджеры, часы работы, карта;
   - `sections` — какие разделы показывать (`false` прячет раздел вместе с пунктом меню).
3. Поменяйте `<title>`, `description` и `og:` в начале `index.html` (их читают поисковики и мессенджеры при отправке ссылки).
4. Поставьте `demoMode: false`.
5. Заполните `privacy.html` данными владельца.

### Что делает `demoMode`

- `true` (показ клиентам): сверху полоса «Демо-шаблон» с переключателем типа бизнеса, пустые контакты показаны как заглушки с пометкой «демо», на стоковых фото подпись «Фото для примера».
- `false` (рабочий сайт): всё демо скрыто, незаполненные контакты и карта не показываются совсем.

Переключить тип в демо можно и ссылкой: `index.html?type=barber`. Удобно, чтобы отправить клиенту пример под его бизнес.

В демо-полосе есть 5 цветов акцента (бирюзовый, бордовый, оливковый, графитовый, пудровый). Выбранный цвет сразу попадает в адрес страницы, его можно комбинировать с типом: `index.html?type=nails&accent=powder`. Варианты `accent`: `teal`, `wine`, `olive`, `graphite`, `powder`. На рабочем сайте цвет задаётся в `config.js` (`accent`).

### Цены

В шаблоне цен нет. Когда клиент даст прайс, добавьте у услуги поле `price: "от 1 500 ₽"`, и оно появится на карточке.

### Фото

- Первый экран и «О студии» сейчас показывают бесплатные фото с Unsplash (авторы указаны в `config.js`). Они лежат в `assets/img`, а не грузятся с чужого сервера: ссылки на сторонние сайты у части посетителей (особенно на мобильном интернете) могут не открываться. Для клиента замените их фото его салона и тоже кладите в `assets/img`.
- Для первого экрана есть две версии: `hero.jpg` (горизонтальная, ~2000 px) и `hero-mobile.jpg` (вертикальная, ~900 px, для телефонов, указывается в `srcMobile`).
- `og.jpg` (1200×630) — картинка, которую мессенджеры показывают рядом со ссылкой. В `index.html` в `og:image` нужен полный адрес сайта клиента.
- Пустые рамки в галерее — места под реальные работы. Рекомендуемые пропорции подписаны в самих рамках. Размер файла лучше держать в пределах 300 КБ (формат JPG или WebP, ширина 1600 px).
- Настоящие фото в галерее открываются по нажатию в увеличенном просмотре.

## Обновление сайта и кэш браузера

Браузеры посетителей запоминают стили и скрипты. Чтобы после правок все сразу увидели новую версию, в `index.html` и `privacy.html` у ссылок на `assets/css/…` и `assets/js/…` стоит номер версии `?v=20261025-6`. При каждом обновлении меняйте его на новый (например, на сегодняшнюю дату) во всех ссылках сразу.

## Как подключить форму заявок

Пока `form.endpoint` пустой, форма проверяет поля, но заявку никуда не отправляет. Посетитель видит честное сообщение, что отправка не подключена.

Чтобы заявки приходили, в `config.js` укажите адрес обработчика `form.endpoint`. Форма отправляет POST-запрос с JSON:

```json
{ "name": "", "phone": "", "contactMethod": "Звонок", "service": "", "date": "", "time": "", "comment": "", "consent": true, "page": "" }
```

Успехом считается только ответ сервера с кодом 200–299. Варианты:

1. **Telegram через свой хостинг** (рекомендуется): загрузите `examples/send-telegram.php` на хостинг с PHP, впишите токен бота и chat id (инструкция в начале файла), укажите `endpoint: "/send-telegram.php"`. Токен остаётся на сервере.
2. **Formspree** или похожий сервис: зарегистрируйтесь, создайте форму, укажите её адрес вида `https://formspree.io/f/xxxxxx`. Заявки придут на почту.
3. **Make / Zapier / n8n**: создайте вебхук и укажите его адрес, дальше заявку можно отправить куда угодно (Telegram, Google Таблицы, CRM).

Секретные ключи и токены никогда не вставляйте в `config.js`: этот файл видит любой посетитель.

- [ ] `demoMode: false`
- [ ] Название, тексты и услуги согласованы с клиентом, лишние услуги удалены
- [ ] Контакты реальные, ссылки на звонок и мессенджеры открываются
- [ ] Форма отправляет тестовую заявку, и она доходит
- [ ] `privacy.html` заполнен
- [ ] Фото заменены на фото салона, у фото есть описания (`alt`)
- [ ] Сайт проверен на телефоне
